# docs/ — dla większych projektów

Gdy projekt urośnie, przenieś tu szczegóły z `CLAUDE.md` (wzór: `projects/ewa-dabrowska/docs/`):

| Plik | Po co |
|---|---|
| `brief.md` | Klient, cel strony, odbiorcy, ton |
| `design-system.md` | Kolory, typografia (ID presetów), komponenty, ruch |
| `framer-map.md` | Strony, sekcje, ID węzłów, kotwice |
| `content-guidelines.md` | Język, ton, alt-teksty |
| `decisions.md` | Log decyzji (data, decyzja, powód) |
| `backlog.md` | Problemy i plan prac z priorytetami |

# Skrzynka inspiracji

Wrzucaj tu screeny (PNG / JPG / WebP) przez GitHub: **Add file → Upload files → Commit changes**.

Link do strony i zdanie „co mi się podoba” napisz Claude’owi w czacie
(albo zawrzyj w nazwie pliku, np. `menu-pelnoekranowe--studio-xyz.com.png`).
Potem napisz: **„przejrzyj skrzynkę inspiracji”**.

Claude skataloguje każdy screen (`../CLAUDE.md`) i usunie go stąd — skrzynka ma być pusta.
